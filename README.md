# Norte OS — POS para transição de carreira tech

Sistema Operacional Pessoal da Gabriela: sair do Cartório de Registro de Imóveis e autogerenciar **UniFECAF**, **Rocketseat**, **portfólio** e **candidaturas/freelas**.

Disciplina: Produtividade e Gestão do Tempo (UniFECAF).

## Ferramentas

- Norte OS (este app) — equivalente a um workspace Notion (bases + dashboard + IA)
- Google Drive com pastas PARA (Áreas, Projetos, Recursos, Arquivo)
- Métodos: GTD, Eisenhower, Pomodoro, PARA, time blocking
- IA Grok: resumir aula, plano da semana, priorizar backlog, rascunhar proposta
- Referências: Notion Guides, Trello Guide, Asana Academy

## Fluxo

1. Capturar ideia, nota ou tarefa no **Segundo cérebro** (inbox → esclarecer)
2. Eisenhower: código e portfólio no quadrante 2; LinkedIn sem fim no 4
3. Manhã = Pomodoro de prática · tarde = UniFECAF · lote = candidaturas
4. Mover projetos (ideia → GitHub) e leads no **Segundo cérebro**
5. Documentos no **Google Drive** (pastas PARA). Notas de aula no app.
6. Domingo: revisão semanal — sem candidatar nesse bloco

## Como usar

Painel, Tarefas, Agenda, Foco, Segundo cérebro, Copiloto, Comunicação.
Os dados ficam no navegador neste momento. “Restaurar demonstração” no rodapé do menu recarrega o recorte da transição.
